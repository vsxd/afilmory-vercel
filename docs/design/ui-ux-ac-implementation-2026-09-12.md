# 查看器 A/C 实施记录

日期：2026-09-12。范围来自用户对[差异复核](ui-ux-directions-2026-09-12.md)的选择：先 A/C，B 暂缓。本轮沿用现有照片墙、搜索筛选规则、照片顺序与地图能力。

## 可见变化

- 查看器工具栏增加来源与序号。来源和实际照片集合一起解析，显示全部照片、当前筛选、地图照片或未知自定义集合的浏览序列。搜索命中筛选外照片、地图单点打开但未指定照片组等情况仍按真实全库/筛选范围显示，继续切图后不变成错误的地图范围。
- EXIF 按参数、器材、拍摄模式、富士设置、影调、地点、标签、文件与技术信息排列。复用已有内容；桌面默认 320px 信息栏与缩略图条保留。
- 手机信息面板从底部覆盖层改为布局中的独立分区。竖屏上方是照片和缩略图条，下方是可滚动信息；短横屏使用左右分区。
- “更多照片空间”“更多信息空间”在三档比例间调整。信息默认占 44%，两端为 34% 和 54%；横屏信息区保留最小可读宽度。按钮不依赖拖拽，边界禁用，状态通过读屏器播报；六种语言均有文案。
- 关闭信息后焦点返回信息按钮。下方信息区承担手机底部安全区，避免缩略图条重复预留。

## 几何与渲染

- 开合信息、调整空间和旋转时，移动端照片重新适应实际媒体区域，复用已加载图片。为保证完整构图，布局变化后会复位手动缩放。
- 入场/退出动画优先读取真实媒体视口。尺寸变化由 `ResizeObserver` 记录；关闭时 DOM 已卸载也可使用最后的矩形。旧的全屏减固定栏计算只作为缺少媒体 ref 时的兼容回退。
- 在入场动画期间打开信息，会先结束旧目标动画，再分配照片与信息空间。
- WebGL 回归同时覆盖系统减少动态效果，确保不会因动画设置更新误触发普通图片渲染回退。

回归中修复了一个已有 WebGL 生命周期问题：减少动态效果的初始状态原先在 effect 中更新，导致引擎立即销毁并复用已经释放的 canvas context，初始化失败后回退 DOM。现在首次构造读取正确偏好，后续偏好或 `smooth` 变化通过引擎方法原位更新；不重建 GPU context/worker、不重载图片。启用减少动态效果时停止当前动画，后续复位和双击遵循该偏好。
