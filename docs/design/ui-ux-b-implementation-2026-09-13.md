# 搜索与筛选 B 实施记录

日期：2026-09-13。用户否决原 B 的并排侧栏后，确认了保留沉浸式模态的交互稿。本次实现以该修订稿为准。

## 界面与交互

- 保留底部呼出、整墙模糊、背景隔离和下拉关闭，照片墙宽度不随搜索开合改变。未实施原提案的侧栏、瀑布流重排或手机两档停驻高度。
- 精简面板标题区，在搜索框下固定显示照片墙的匹配数；已选条件仍可逐个移除。清除条件与清除查询分开，底部“查看 N 张照片”只收起面板，条件始终即时生效。
- 搜索结果分为筛选/动作和照片两组，默认筛选在前；筛选最多展示 20 项、照片最多展示 10 项，分别计数，照片不再被筛选命令挤掉。照片组注明全库查询范围，展示条数不冒充所有命中数。
- 照片预览改为 96×72px 区域内完整显示构图，原比例占位图与缩略图共用同一个适配盒子。照片说明最多显示两行；地点使用当前语言的去重省市区，完整多语言检索词继续留在索引中。
- 首次打开才懒加载搜索模块；同一页面会话中保留查询、键盘选中项和列表滚动。手动关开可继续搜索，从搜索进入照片后，切图再关闭或浏览器后退也会恢复现场。刷新开始新会话。
- 只在返回原历史记录时自动恢复；跳到其他页面、浏览器前进到照片、直接打开照片不会误恢复搜索。等待照片路由退出，避免搜索覆盖查看器退场。

## 工程与可访问性

- 分组/限额在命令模型中维护，`CommandResultGroups` 承担结果呈现，`useCommandPaletteSession` 管理会话与路由衔接。既有筛选组合、照片顺序和查看器集合规则保持一致。
- 已经由照片索引匹配的结果不再按展示文案二次过滤，修复仅命中相机或镜头元数据时照片被漏掉的问题。缩略图组件新增显式 `fit` 参数，默认行为仍为 `cover`。
- 继续复用共享材质与控件配方；面板材质和短视口布局由 gallery 样式维护，通过局部变量调整尺寸，避免与 Tailwind 的 utility 层竞争。
- 焦点初始化只在弹层打开时采样，输入过程不重建焦点作用域。搜索暂时让位给查看器时保留首次入口；返回后聚焦原结果，最终关闭归还入口。方向键支持输入框与已聚焦的结果按钮，Enter 保留正确的单次执行。Tab 循环排除被祖先或响应式样式隐藏的控件。
- 搜索覆盖查看器时使用已有嵌套浮层标记，防止 Escape 和切图快捷键穿透。
- 手机面板跟随 `visualViewport` 的位置和大小。极短视口下暂时隐藏重复标题和已选条件栏，匹配数仍在底部操作中显示，给查询与结果留出空间。关闭键盘后恢复完整面板。
- 六种语言同步更新，并删除失去引用的旧文案。
