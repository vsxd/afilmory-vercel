# UI/UX 首轮实施记录

日期：2026-09-11。基于[已确认的设计方向](ui-ux-review-2026-09-11.md)，改进现有摄影作品墙的界面与交互。

## 完成内容

- 建立普通面板、弹层、照片上覆控件、按钮和复合输入框的共享样式；统一暗色底、边框、阴影和焦点。保留照片取色背景，确保明亮图片上的操作仍有稳定深色底。
- 作者卡保留身份、社交、搜索、地图、视图和统计；手机内部改为紧凑排版，站点名称支持换行。桌面继续嵌入原比例虚拟照片墙，默认 4px 间距、排序和列数设置保持。
- 照片悬停与键盘聚焦共用信息呈现，调整遮罩、参数排版及缩放反馈。保持触摸浏览时的轻量渲染。
- 手机长滚动后显示已有三个操作。浮动触发器保留实例，打开弹层和排序导致滚动重置时仍能正确恢复焦点；协调日期条与底部安全区。
- 搜索保持原命令与照片索引、筛选 ID 和组合规则。器材名称与结果支持完整换行，设备筛选在桌面双列、手机单列展示，选中有明确勾选标记；复合搜索框只绘制一层焦点。
- 作者卡的已选条件可直接取消，零筛选结果可以原地清空条件并保留排序；搜索零匹配可以清空查询并保留已应用的筛选。
- 查看器保留桌面常驻 320px EXIF、默认缩略图条和媒体几何。统一 EXIF 数据行、专业参数、长值换行、分组、缩略图选中与工具栏样式。
- Raw EXIF 增加可见关闭，关闭时取消未完成的解析请求，避免迟到结果重新打开弹窗。Escape 只关闭当前嵌套层。分享菜单使用完整的菜单语义和键盘操作，复制链接保持原有照片 URL。
- 地图控件与各类标记浮层使用同一材质；统计和坐标的层级更清楚，手机信息卡可滚动。聚合“更多照片”可进入第一张尚未显示的照片，查看器保留整组照片序列与地图返回上下文。
- 统一地图加载/失败、照片加载、分享和 Raw EXIF 的状态表达。新增文案覆盖六种语言。

## 验证

- 全量单元测试：208 个文件、1408 项通过。
- 全局覆盖率：Statements 74.75%、Branches 66.29%、Functions 76.28%、Lines 75.95%；全局与分区门槛均通过。
- 完整工具、workspace、前端测试与 Worker 类型检查通过；ESLint、格式、workspace contracts、secret scan 通过。
- 开发端到端：15 项通过，4 项按设备预期跳过。
- 生产静态构建与端到端：10 项通过，包含原图加载、资源释放、路由/地图往返、缩略图浏览上下文、分享与 reduced motion。
- WebKit / iPhone 模拟浏览：2 项通过。
- 新增行为验证包括手机浮动入口、真实键盘焦点描边、排序后焦点恢复、空结果恢复、精确筛选 ID、Raw EXIF 关闭与迟到结果、分享键盘菜单及地图聚合连续浏览。

使用现有本地 manifest 的 172 张真实照片检查首页、搜索和手机排版；390px 模拟视口未出现横向溢出。该预览使用独立配置，未改动站点私有环境文件或生成 manifest。线上库和本地库的照片及作者配置不同，不将两次截图的尺寸差异宣称为严格的前后指标。

本地来源对远程原图的访问出现连接失败，因此真实照片预览用于检查视觉与错误状态；原图成功加载及生产媒体路径通过受控照片 fixture 的生产回归验证。浏览器截图工具在部分桌面视口存在缩放/裁切问题，不据此推断产品裁切缺陷；EXIF 数据边界另外检查了 DOM 实际矩形。

本轮没有进行真实手机硬件测试、访客研究或性能基准测量，不宣称帧率、加载速度或转化率提升。

## 保持的边界

产品继续使用密集作品墙、嵌入作者卡、统一搜索筛选、连续查看器与地理探索。没有加入博客、策展、归档、新导航模式、默认折叠 EXIF 或新的搜索/地图范围。

Builder、存储、schema、PhotoRepository、媒体服务、WebGL 引擎与导航控制器不因这次视觉工作重写。浏览器回退、滚动和焦点恢复、媒体取消、按需加载及静态部署契约继续由现有测试覆盖。
